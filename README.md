# Jot

把文件放上来，开始处理。Jot 是 Swift + AppKit 编写的 macOS 原生本地数据工作台：文字、JSON、表格、PDF、图片和其他文件都可以放到自由画布，拖动卡片并排比较，提取或转换后的结果另存为新卡片。

保留石墨灰「圆点 + 小写 j」标志、半透明侧栏与灰白色内容卡片。macOS 26+ 使用原生 Liquid Glass，macOS 27+ 启用玻璃控件交互反馈；macOS 13–25 使用原生兼容控件与半透明材质。窗口左上角使用系统原生关闭、最小化和缩放按钮；macOS 26+ 采用统一工具栏标题栏，随 macOS 27 的系统样式呈现。明暗模式跟随系统，无第三方依赖。

## 使用

双击 `dist/Jot.app`。点击「添加文件」、把文件拖入画布，或用 ⇧⌘V 把剪贴板中的文字、图片、文件粘贴为新卡片。新建文本会直接打开编辑窗口。窗口右上角「查找替换」或 ⌘F 可打开双行面板，支持匹配高亮、大小写／完整词语、单次和全部替换；⌘Z 可撤销替换。新粘贴或添加的内容会排在左侧列表最前面；「整理排列」也按最新添加优先排列。

- 拖动卡片标题自由排列；拖动右下角调整尺寸。画布支持 35%–200% 缩放和整理排列。
- 双击卡片标题或点击「专注查看」打开独立窗口；文本在此编辑，PDF、图片和其他文件在此预览。可同时打开多张卡片。
- 侧栏按类型筛选、搜索名称与文本内容，点击条目定位卡片。搜索不自动提取 PDF 或图片文字。
- 选中卡片后点击「卡片工具」使用相应工具。处理作用于整张卡片，生成新卡片并保留原内容；结果可通过「定位来源卡片」回到来源。
- 每张卡片右上角提供复制、删除（⌘Z 可撤销）和展开编辑／预览三个方形按钮。支持复制文本全文和导出当前卡片。画布上的添加、移除、移动、缩放尺寸与整理排列支持撤销；专注窗口使用原生文本撤销重做。

## 文件与处理能力

| 内容 | 当前能力 |
| --- | --- |
| 文本 / JSON | 原生编辑、查找替换、代码字体、字号及换行调整；JSON 格式化、去除行首尾空格、空白行和重复行，均生成新卡片 |
| CSV / TSV | 只读表格预览与可编辑原文切换；首行作为列名；原样导出当前 CSV/TSV 原文，或转换为 JSON |
| PDF | PDFKit 预览；提取已有文字层，按页生成一张文字结果卡片 |
| 图片 | 图片预览；Vision 本机 OCR，支持简体中文、繁体中文与英文，输出可编辑文字卡片 |
| 其他文件（含 Excel） | 保存本机副本；专注窗口使用系统 Quick Look，或通过「打开导入时的原件副本」交给系统应用 |

表格导出不要求原文能成功解析；导入的 TSV 保留 `.tsv` 扩展名，其他表格默认使用 `.csv`。

表格转 JSON 要求首行列名非空且不重复、各行列数一致；值均保留为字符串。JSON 转表格接受非空对象数组，列名取全部对象键并排序，缺失值和 null 变为空单元格，嵌套对象与数组序列化为 JSON 字符串。

单个导入文件最多 100 MB，文本导入或粘贴最多 10 MB；表格解析最多 20,000 行（含首行）、200 列。文本文件支持 UTF-8，以及带 BOM 的 UTF-16。扫描 PDF 没有文字层时不能直接提取，可先在其他应用将页面导出为图片，再导入识别。OCR 可能误识别，使用结果前请核对。Excel 当前没有原生表格编辑或格式转换功能。

## 本地保存

停止编辑或调整布局约 0.5 秒后自动保存，关闭窗口或退出时也会保存。默认数据目录是 `~/Library/Application Support/Jot/`：

- `workbench.json`：卡片内容、位置、尺寸、缩放及来源关系。
- `workbench.backup.json`：上一份有效工作台备份。
- `attachments/`：导入文件与粘贴图片的本机副本。

首次找不到工作台文件及备份时，会从旧版 `drafts.json` 迁移草稿，原草稿文件保留。移除卡片可在当前会话撤销；附件文件暂不自动清理，移除卡片不会释放对应附件的磁盘空间。导入文本的编辑内容保存在工作台中，「打开导入时的原件副本」打开的是导入副本；导出文本卡片才会写出当前编辑内容。

Jot 无需账户，PDF 文字提取、图片 OCR 和转换都在本机完成。迁移或备份整个工作台时，请同时保留 JSON 文件与 `attachments/`。保存失败会显示提示；不可读取或版本不兼容的数据会被保留，并暂停覆盖保存。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建文本卡片 | ⌘N |
| 添加文件 | ⌘O |
| 粘贴为新卡片 | ⇧⌘V |
| 导出当前卡片 | ⇧⌘S |

| 查找下一处 / 上一处 | ⌘G / ⇧⌘G |

| 关闭窗口 / 退出 | ⌘W / ⌘Q |

## 开发与打包

运行需要 macOS 13+；编译需要带 macOS 27 SDK 的 Xcode 或相应 Swift 开发工具。

```sh
swift run Jot
swift test
bash scripts/build-app.sh
open dist/Jot.app
```

在 Xcode 中打开 `Package.swift` 可以直接编辑与调试。打包脚本显式使用当前 Xcode 的 macOS SDK，并校验二进制中的 SDK 版本；最低运行系统仍为 macOS 13。脚本使用本机架构，当前产物为 Apple Silicon 版本。`Jot.app` 使用本地临时签名，尚未进行 Developer ID 签名或 Apple 公证。

修改图标时，同步更新 `Resources/icon.svg` 与 `Sources/Jot/Components.swift` 中的 `LogoView`，再运行 `bash scripts/build-icon.sh`（需要 `rsvg-convert`、系统自带的 `sips` / `iconutil` 和 Python 3），重新生成 PNG、各尺寸图标、ICNS 及来源记录，最后运行打包脚本。

测试独立数据目录时可使用：

```sh
JOT_DATA_DIR="$PWD/.local-data" swift run Jot
```

`prototype/` 保留早期网页视觉参考，不参与客户端构建。
